# WEIGHT APP

Aplicación móvil para el control de peso, desarrollada con la metodología Scrum y las herramientas A, B y C.

## FUNCIONALIDADES

- Registro e inicio de sesión
- Registro de alimentos
- Registro de ejercicios
- Registro de rutinas
- Prospecto de dietas
- Perfil de usuario
- Foro
- Página de compra
- Panel administrativo

## EQUIPO

- Lariosk
- Colaborador 1
- Colaborador 2

## METODOLOGÍA

- Scrum
- GitHub Projects
- Iterative development
